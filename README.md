# Umaima Rahman

Personal website: https://rumaima.github.io/umaimarahman.github.io/

The whole site is `index.html` (plain HTML and CSS, no build step). Edit it directly and push to `main`; GitHub Pages serves it as is.

- Add a paper: copy an `<article class="pub">` block in the Publications section.
- Add news: add an `<li>` at the top of the News list; move older items into "Earlier news".
- Photo: `images/portrait.jpg` (square). The annotation box position is set in `.bbox` in the CSS.
